I made this website on my free time as a small project. 
The purpose of it is to distribute coins among a party in a DnD setting.
You can select whether the party is using electrum pieces or not. And the party size input MUST be entered.
As for all the other input values, it is fine to ommit it, it will consider the default value (which is null).


The code is still messy and will keep upgrading it as time goes on.
